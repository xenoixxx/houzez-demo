Full scope, as I understand your brief

  • Payment gateway reset: undo the earlier child-theme customisation that blocks the "free membership" option when Free Submissions is set to NO, so all four Houzez payment modes (free, per listing, featured, membership) follow default Houzez behaviour again.
  • Strikethrough text field: reconnect the existing backend field to the second price line on the membership package cards.
  • Red line rules: move the red strikethrough from the first price line to the second, controlled by an Activate/Deactivate option in the package settings.
  • PayPal live payments: configure the live PayPal option and fix the "Ooops page not found" error at checkout. This usually means the Payment Page template page is missing, or the return/thank-you URLs point to a page that no longer exists.

Where the frontend change lives

A sketch of the child-theme override. The exact template file and meta key will be confirmed against your Houzez 4.4 install during the scope session.

// child-theme: template-parts/membership/package-price.php (override)
$price       = get_post_meta( $package_id, 'fave_package_price', true );
$strike_text = get_post_meta( $package_id, 'fave_package_strike_text', true ); // existing custom field
$red_line    = get_post_meta( $package_id, 'fave_package_strike_active', true ) === 'yes';

echo '<div class="pkg-price-1">' . esc_html( '$' . number_format( (float) $price, 2 ) ) . '</div>';
if ( $strike_text !== '' ) {
    printf( '<div class="pkg-price-2%s">%s</div>',
        $red_line ? ' is-struck' : '', esc_html( $strike_text ) );
}
